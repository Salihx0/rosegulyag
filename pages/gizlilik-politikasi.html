Gizlilik Politikasi

Son guncelleme: 15 Ocak 2025

1. Giris

BRR ROSE olarak gizliliginize saygı duyuyor ve kisisel verilerinizin korunmasina buyuk onem veriyoruz. Bu gizlilik politikasi, web sitemizi ziyaret ettiginizde hangi verilerin toplandigi, nasil kullanildigi ve korundugun hakkinda sizi bilgilendirmeyi amaclamaktadir.

2. Toplanan Bilgiler

2.1 Otomatik Olarak Toplanan Bilgiler

Web sitemizi ziyaret ettiginizde, asagidaki bilgiler otomatik olarak toplanabilir:

  • IP adresi
  • Tarayici turu ve surumu
  • Isletim sistemi
  • Ziyaret edilen sayfalar ve ziyaret suresi
  • Yonlendiren URL
  • Cihaz bilgileri

2.2 Sizin Tarafinizdan Saglanan Bilgiler

Iletisim formumuz araciligiyla asagidaki bilgileri bize iletebilirsiniz:

  • Ad ve soyad
  • E-posta adresi
  • Mesaj icerigi

3. Cerez Politikasi

3.1 Cerez Nedir?

Cerezler, web sitemizi ziyaret ettiginizde cihaziniza yerlestirilen kucuk metin dosyalaridir. Bu dosyalar, web sitesinin duzgun calismasi, kullanici deneyiminin gelistirilmesi ve site kullaniminin analiz edilmesi icin kullanilir.

3.2 Kullanilan Cerez Turleri

  • Zorunlu Cerezler: Web sitesinin temel islevlerinin calismasi icin gereklidir (tema tercihi, dil secimi gibi).
  • Performans Cerezleri: Web sitesinin performansini ve kullanimini analiz etmek icin kullanilir.
  • Islevsel Cerezler: Kullanici tercihlerini (dil, tema) hatirlayarak kisislestirilmis bir deneyim sunar.

3.3 Cerezleri Yonetme

Tarayicinizin ayarlarindan cerezleri devre disi birakabilir veya silebilirsiniz. Ancak bu durumda web sitemizin bazi ozellikleri duzgun calismayabilir.

4. Verilerin Kullanim Amaci

Toplanan veriler asagidaki amaclarla kullanilir:

  • Web sitesinin duzgun calismasini saglamak
  • Kullanici deneyimini iyilestirmek
  • Iletisim taleplerinize yanit vermek
  • Web sitesi trafikini analiz etmek
  • Guvenlik onlemlerini uygulamak
  • Yasal yukumlulukleri yerine getirmek

5. Verilerin Paylasilmasi

Kisisel verileriniz, yasal zorunluluklar disinda ucuncu taraflarla paylasilmaz. Verilerin paylasilabilecegi durumlar:

  • Yasal zorunluluk bulunmasi halinde yetkili makamlarla
  • Hosting ve teknik altyapi hizmeti saglayicilariyla (gizlilik sozlesmesi kapsaminda)
  • Analitik hizmet saglayicilariyla (anonimlestirilmis veriler)

6. Veri Guvenligi

Kisisel verilerinizin guvenligini saglamak icin asagidaki onlemleri almaktayiz:

  • SSL/TLS sertifikasi ile sifrelenmis veri iletimi
  • Guvenli sunucu altyapisi
  • Duzenlii guvenlik guncellemeleri
  • Erisim kontrolu ve yetkilendirme mekanizmalari

7. Ucuncu Taraf Baglantilari

Web sitemiz, ucuncu taraf web sitelerine baglantilar icerebilir. Bu web sitelerinin gizlilik politikalari uzerinde hicbir kontrolumuz bulunmamaktadir. Bu nedenle, ucuncu taraf web sitelerini ziyaret ettiginizde ilgili sitelerin gizlilik politikalarini incelemenizi oneririz.

8. Cocuklarin Gizliligi

Web sitemiz 18 yasindan kucuk cocuklara yonelik degildir. Bilerek 18 yasindan kucuk kisilerin kisisel verilerini toplamiyoruz.

9. Haklariniz

Kisisel verilerinizle ilgili haklariniz hakkinda detayli bilgi icin KVKK Aydinlatma Metnimizi inceleyebilirsiniz.

10. Degisiklikler

Bu gizlilik politikasi zaman zaman guncellenebilir. Degisiklikler web sitemiz uzerinden yayinlanacaktir. Bu sayfayi duzenlii olarak kontrol etmenizi oneririz.
